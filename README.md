# JG법령검색 웹판

국가법령정보센터 OPEN API 자료(JG법령수집으로 받음)를 검색하는 웹 페이지입니다. 설치 없이 브라우저에서 열립니다.

- **주소**: 이 저장소의 GitHub Pages 주소 (Settings → Pages에 나옴)
- **할 수 있는 것**: 법령·판례·해석례·재결례·행정규칙 검색, 조문 보기, 법령 필터, 🕸 법령 연계도
- **Claude 기능**(Claude에게 묻기, ⚖ 충돌·중복 분석, AI 요약): 이 페이지는 claude.ai 밖이라 질문과 받은 DB 자료를
  복사해 내 Claude 채팅에서 묻는 방식으로 동작합니다. 페이지 안에서 바로 답을 받으려면 claude.ai 아티팩트판을 쓰세요.

## 자료 바꾸기
1. JG법령수집 → [아티팩트용 내보내기] (저장 폴더 안 `아티팩트용` 폴더)
2. 그 폴더의 파일들로 이 저장소의 `data/` 폴더를 바꿉니다.
   - GitHub 웹: `data` 폴더 → Add file → Upload files (한 번에 100개까지라 몇 번에 나눠 올림)
   - 또는 GitHub Desktop으로 폴더째 바꾸고 Commit → Push
3. 1~2분 뒤 페이지에 새 자료가 보입니다(브라우저 새로 고침).

자료 출처: 법제처 국가법령정보센터 (https://www.law.go.kr). 이 페이지는 업무 참고용이며 법적 효력이 없습니다.
